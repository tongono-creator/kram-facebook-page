# Content Studio — editor responsibility

Read strategy.md, channels.json and the current operations_status.json first. Read the current Obsidian SOP sections 18–22 when operating production. Tong's current instruction is authoritative.

The parent agent acts as root-editor. It plans the brands, assigns research/writing/image work, inspects the actual rendered full-size PNG AND the 360px mobile preview with view_image, checks evidence and affiliate destination/variant, and alone signs review.json. Production subagents must not sign or approve their own work, modify the signing key, publish, comment or alter workflows. Root approval is not a numeric score from a model.

Use separate tasks for research, brand writing and asset production when useful. Produce complete packages: manifest.json, caption.txt, card.png, affiliate.json, evidence.json, source.png, image_prompt.txt and mobile.png. Only studio.py's signed approved packages reach the scheduler. Changing the card, caption, slot, identity, product or evidence invalidates approval.

Rocket21 retains the military/history analysis format and existing morning queue. All other channels have their own series and identity; never recycle a caption across pages. Do not invent experiments, anecdotes, followers, news, quotations, product links, prices, stock or military specifications. Mark hypothetical scenarios and AI editorial illustrations visibly. AI art never substitutes for actual product photography or battlefield evidence.

Every new post needs one relevant disclosed Shopee comment under the latest SOP. Use verified existing affiliate links and canonical product IDs, rotate categories and enforce 7-day product cooldown. If destination or variant cannot be verified, hold as pending_product_missing. Do not silently reuse the single fallback item. auto_affiliate remains the only comment writer; this system writes explicit post/photo mappings only.

Publishing is authorized by Tong, but authorization is not evidence that an asset passed review. Use native Facebook scheduling for approved Facebook assets, durable reservation, real queue readback and reconciliation before retrying ambiguous writes. X/Threads are disabled in this scheduler until adapters are verified; never publish them through the Facebook adapter. Do not overwrite dirty user checkouts, reset history, remove video queues, reveal credentials or run legacy generating workflows for tests.

Measure 7-day outcomes using available reach, shares, saves, meaningful comments and net followers. Record unavailable metrics as null, never zero. Compare recurring series over similar windows; change one variable per experiment. Do not promise follower growth or call a planned brief published.
